# Olist Analytics Engineering Projet

Transformation des données e-commerce Olist via dbt sur BigQuery. 

## Objectifs - Modélisation des données (staging → intermediate → marts)
- Tests de qualité de données
- Documentation automatique 
- Pipeline CI/CD 

## Architecture prévue
- **staging** : nettoyage des tables sources Olist
- **intermediate** : jointures logiques
- **marts** : tables finales orientées métier (faits/dimensions)
